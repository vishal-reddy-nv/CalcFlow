Support & Resources

Help Center & Frequently Asked

Have questions about how CalcFlow processes formulas or uses local storage? We have answers.

CalcFlow only uses standard, offline chrome.storage.local capabilities to automatically store your customizable active theme settings, calculation scratchpad logs, quick motivates streak counters, and math notes. No remote network connections are requested or tracked, guaranteeing complete privacy.
Standard calculators use JavaScript's built-in eval() statement to resolve equations, which runs arbitrary strings as code. This poses severe script injection security vulnerabilities. CalcFlow implements a secure **Lexical Tokenizer and Recursive Descent Parser** built strictly in accordance with modern security principles, which handles calculations entirely in isolation.
CalcFlow currently supports standard arithmetic infix operations (PEMDAS priority math), floats, parenthetical nesting, decimal operations, percentages, and modulo operators. You can also utilize the **Quick Notes** side panel to temporarily jot down numbers and copy/paste them back into the active expression.
Yes, 100%! All dependencies, stylesheets, and mathematical models are completely packaged locally in the extension. No remote code is retrieved or executed, matching Chrome Extension Web Store's strictest Manifest V3 guidelines.
